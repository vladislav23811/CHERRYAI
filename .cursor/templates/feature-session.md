# Feature Session Template

Use this template when starting a new feature implementation to ensure the AGI Genie follows the correct execution engine.

**Instructions:** Copy the block below and paste it into Cursor Composer or Chat.

---

```text
@agi-genie-core.mdc @agi-execution-engine.mdc

## Session: Feature Implementation
**Feature Name:** <Insert Feature Name>
**Goal:** <Describe what needs to be built>
**Context/Constraints:** <Any specific libraries, UI requirements, or architectural constraints>

## Execution Plan Request
Please begin the AGI Execution Engine process:
1. **Define Phase**: Summarize the goal, list required tools/MCPs, and state any assumptions.
2. **Design Phase**: Propose the architecture, component structure, and state management.

Pause for my review after the Design Phase. Once approved, we will proceed to the Deliver Phase.
```
