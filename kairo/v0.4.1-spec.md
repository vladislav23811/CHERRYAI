# Kairo v0.4.1

## Goals

- **Smoke inference backend** (`KAIRO_BACKEND=smoke`) for CI without Ollama/LM Studio.
- **Orbit vault** — server-side transcript archive when `KAIRO_VAULT_DIR` is set.
- **UI** — **Archive to vault** (enabled when vault is on).
- **`kairo-validate.mjs`** — bundle gate + HTTP probes on ports **14746** (vault off) and **14747** (vault on).
- **GitHub Actions** — `.github/workflows/kairo.yml` runs `npm run kairo:ci` from repo root (push to `main` or `cursor/**`, PR paths, + **workflow_dispatch** for manual runs).

## API

| Route | Vault off | Vault on |
|-------|-----------|----------|
| `GET /api/vault/orbits` | 503 | `{ vault_enabled, orbits[] }` |
| `POST /api/vault/orbits` | 503 | 201 + orbit record (`*.orbit.json`) |
| `GET /api/vault/orbits/:id` | 503 | 200 / 404 |
| `DELETE /api/vault/orbits/:id` | 503 | 204 / 404 |

`GET /health` and `GET /api/meta` include `vault_enabled: boolean`.

## CI

```bash
npm run kairo:ci   # from repo root
```

Smoke reply: `KAIRO_SMOKE_REPLY` or `SMOKE_REPLY` (default `probe-reply-alpha`).

Do not commit `kairo-bundle/`, `kairo-bundle.tar.gz`, `.kairo/`, `.kairo-validate/`.
